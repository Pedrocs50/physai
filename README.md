# PhysAI

IA interpretável para eventos extremos.

Este projeto reúne dados, cenários sintéticos, métodos físicos, modelos e ferramentas de explicabilidade para estudar fenômenos complexos em séries temporais.

- Site: https://example.com/physai
- Documentação: https://physai.readthedocs.io
- Código: https://github.com/helioai/physai

## Visão
A ideia central é combinar conhecimento físico, modelagem temporal e explicabilidade para produzir modelos confiáveis em cenários extremos.

## Estrutura
- Dados: fontes e carregadores
- Modelos: baselines e redes neurais
- Explicabilidade: SHAP, occlusão e interpretação
- Relatórios: resultados reprodutíveis e documentação
