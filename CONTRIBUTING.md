# Contribuindo

## Primeiros passos
1. Crie um ambiente virtual com `uv` ou `venv`.
2. Instale as dependências de desenvolvimento.
3. Execute os testes locais antes de abrir um PR.

## Estilo
- Use `ruff` para lint.
- Prefira tipagem explícita e docstrings em módulos públicos.
- Mantenha notebooks e scripts reprodutíveis.

## Testes
- Execute `pytest` para validar regressões.
- Use `nox -s tests` para a rotina padrão.

## Documentação
- Atualize a documentação e os exemplos quando houver mudança de API.
- Mantenha a referência em linha com as docstrings.
