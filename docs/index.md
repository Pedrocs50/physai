# PhysAI

Documentação inicial do projeto de IA interpretável para eventos extremos.

## Visão geral
Este projeto reúne dados, cenários sintéticos, modelos e ferramentas de explicabilidade para investigar fenômenos físicos e eventos extremos.

## Estrutura
- Dados: carregadores e qualidade de dados.
- Modelos: baselines e redes para séries temporais.
- Explicabilidade: SHAP, occlusão e outras técnicas.
- Relatórios: geração automatizada de resultados e documentação.
